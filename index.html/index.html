TCP vs Coordenadas de Base

Matrices de transformación homogénea para trasladar la cinemática desde el pedestal del robot (Base) hasta la punta de corte o pinza activa (TCP).

NIVEL 1 // BÁSICO
⚡

MoveJ (Articular) vs MoveL (Lineal)

MoveJ mueve cada motor por su trayectoria más rápida minimizando esfuerzo. MoveL fuerza al TCP en línea recta euclídea, esencial para sellado o mecanizado.

NIVEL 2 // INTERMEDIO
🛡️

Seguridad ISO/TS 15066 Cobots

Límites biomecánicos de fuerza y presión en caso de contacto accidental, sensores de par articular e interlocks virtuales SIL-3 de parada segura.
